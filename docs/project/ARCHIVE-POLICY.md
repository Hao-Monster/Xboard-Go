# 历史资料归档策略

`docs-dev/` 保存本地取证、逐日工作记录和可能包含环境细节的原始材料，继续由 `.gitignore` 隔离。它不是项目当前事实源。

## 提炼规则

- 只把仍有效、可公开、可验证的结论提炼到 `docs/project/`。
- 提炼时记录原始文件名称、审查日期和基准提交，但不复制密钥、真实数据、原始请求正文、邮件正文或可执行旧队列载荷。
- 历史结论默认标记为 `historical`；必须在当前候选提交重放验证后才能标记 `current`。
- 发生冲突时，以当前代码、固定证据、已解决决策和版本化事实源为准，并登记兼容性例外或风险。
- 不批量提交全部历史日志，也不因清理而删除本地原始证据。
