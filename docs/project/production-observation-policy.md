## 本轮决策

- 不把本地单元测试、短时连接测试或合成数据基准换算成生产用户数或写入吞吐承诺。
- 生产授权与验证结果分开记录。M4-G03 仅代表已获得用户授权；其他发布门禁仍记录实际结果。

## 观测与处置

| 信号 | 采集内容 | 处置 |
| --- | --- | --- |
| 请求负载 | 按固定路由类别聚合请求数、延迟分位数、失败数 | 持续恶化时定位热路径、写入排队与磁盘瓶颈 |
| SQLite | busy/locked 错误、事务延迟、数据库和 WAL 字节数 | 锁争用影响业务时先分析长事务与批量写入，再评估数据库演进 |
| 主机 | CPU、RSS、磁盘剩余空间、I/O 延迟 | 资源不足时调整容量；不得把扩容视为事务正确性的替代 |
| 异步处理 | 待处理任务数、最老任务年龄、重试和失败数 | 处理持续积压及外部服务故障 |
| 恢复 | 备份成功时间、独立副本校验、恢复用时 | 备份不可用或恢复窗口不足时优先恢复运维能力 |

上述指标是待实施或核验的采集清单，不声明当前系统已提供全部指标。不得采集令牌、邮件正文、用户标识、原始请求或 SQL 参数。异常立即处理，不等待观测窗口结束。

需要多主机写入、自动数据库故障切换，或持续写入排队无法通过局部优化缓解时，启动数据库兼容与迁移任务。迁移必须验证事务、幂等、数据对账和回滚，不能只替换 DSN。
