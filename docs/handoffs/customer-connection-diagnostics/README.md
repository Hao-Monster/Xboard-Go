| 决策标签 | 需要确认 | 推荐起点（建议，未视为批准） | 阻塞哪些工作 | 可继续的独立工作 |
| --- | --- | --- | --- | --- |

| B 租约与部署模式 | Go `local` 与 `redis` 模式下是否都提供 detail；可靠时钟、幂等/版本/ACK存储如何保证 | 首版 detail 使用 Redis 权威状态；无 Redis 时明确拒绝 start，保留已有业务与只读查询；不偷偷做多实例不安全内存租约 | 租约持久状态和跨实例实现 | 事件契约、查询、页面、Redis服务原型 |
